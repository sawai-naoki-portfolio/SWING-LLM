# Project Zenith: SWI-LLM について

## 概要
SWI-LLM (Small but Wise and Intelligent Large Language Model) は、Project Zenith によって開発された次世代の超軽量モデルです。わずか150Mパラメータでありながら、大規模モデルに匹敵する「深い思考力」と「ツール操作能力（Agentic）」を持っています。

## 特徴
1. **Multimodal**: テキストだけでなく、画像入力もネイティブで理解する Vision Language Model です。
2. **Test-Time Compute**: o1モデルのような「生成時の長考（思考プロセス）」を導入し、小さな脳でも複雑な推論を解き明かします。
3. **Agentic RAG**: 外部のAPIやナレッジベースを自律的に検索・利用し、自身の知識の限界を超えることができます。

## 開発メンバー
* AIアシスタント: JARVIS (論理的), NAVI (フレンドリー)
* リードエンジニア: ユーザー

このドキュメントはRAGシステムによって動的に参照されます。
